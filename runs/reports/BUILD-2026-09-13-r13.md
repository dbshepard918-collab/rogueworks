# BUILD — 2026-09-13 Round 13: P2.1 Hit Feel (Forge)

**Item:** P2.1 Hit feel — hit-stop frames, knockback curves, hit flash, screen shake with settings toggle, damage numbers with crit styling, impact particles matched to element.

**Fixes this round:**
The P2.1 code was *written* in a prior round but was **non-functional** — three critical bugs prevented the mechanics from working:

1. **`tick_hit_stop()` was never called** — `world.step()` never invoked it on actors, so hit-stop had zero gameplay effect. Fixed: added `tick_hit_stop(dt)` loop over all entities in `world.step()` (after particle updates, before camera follow).
2. **`hit_stop` didn't freeze movement** — `player.tick()` and `monster.tick()` never checked `hit_stop` to prevent actions; `apply_knockback()` still moved entities during hit-stop; `Player.move()` returned movement even when frozen. Fixed: added early-return in all three methods when `hit_stop > 0.0`, plus `_frozen` flag tracking.
3. **No settings toggle** — `Camera.shake_enabled` existed but there was no way to toggle it. Fixed: added `F` key binding in `RunScene.handle_event()`, HUD indicator showing SHAKE: ON/OFF in `hud.py`, `HUD.update()` syncs from `world.camera.shake_enabled`.

**Damage number styling fix:** `combat.py` monster-hit damage numbers were scale 4 gold / scale 3 cream, not matching the spec (scale 3 gold / scale 2 cream, DOT green). Fixed to match `docs/ROADMAP.md` spec exactly.
