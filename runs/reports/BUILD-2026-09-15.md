# BUILD — 2026-09-15 — G-03 Selftest FAIL Fix + validate_data Warnings

**Bot:** forge
**Trigger:** `tools.studio.verify_gate --seeds 0 1 2 --turns 300` returned FAIL (1 gate red: `tools.selftest`). Highest-value open issue: `glyph-coverage` FAIL (missing em-dash glyph).
**Date:** 2026-09-15

## Item

The verify gate was FAILing because `tools.selftest` reported `[FAIL] glyph-coverage — 1 missing glyph(s): ['—']`. The em dash character (U+2014) is used throughout the codebase in comments and strings but had no entry in `FONT_GLYPHS`. `BitmapFont.glyph()` silently fell back to the space glyph, making the character invisible. Additionally, `tools.validate_data` had 3 warnings for newly added narrative files (`npcs.json`, `storyline.json`, `hq_rooms.json` from r46) that weren't registered in the validator's SCHEMAS dict.

## What changed

1. **`game/engine/assets.py`** — Added `'—': "..#/###/###/###/..#"` 3x5 bitmap glyph to `FONT_GLYPHS` (line after `~` entry, before closing `}`).
2. **`tools/validate_data.py`** — Two fixes:
   - Added `npcs.json`, `storyline.json`, `hq_rooms.json` to `SCHEMAS` dict as `_special` files (skips entries validation since these files use non-standard envelopes: `npcs`, `plot`, `rooms` keys instead of `entries`).
   - Changed `if schema.get("_special") and fname == "meta_tree.json":` to `if schema.get("_special"):` so `_special` applies to all files, not just `meta_tree.json`.
   - Added `_special` early-exit in the main validation loop (before the `entries` array check) to skip `entries` validation for special files.
3. **`docs/TICKETS.md`** — Added G-03 ticket entry.
