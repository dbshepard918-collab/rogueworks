# BUILD report — 2026-09-16 (r76)

## Round goal

The r46 narrative content (5 quests, 5-act storyline, HQ hub with NPCs) was half-wired:
quests were accepted and displayed in the HQ, but their objectives were never tracked
during the dungeon run and their rewards were never granted. This round wires the quest
system into the run so the narrative actually connects to gameplay, and fixes the
recurring `secret_wall` warning.

## What changed

1. **Quest tracking during runs** (`game/systems/quest_tracker.py`, `game/systems/world.py`).
   `QuestTracker` is now profile-backed and wired into `World`:
   - `new_floor` → `check_floor_reached(floor)` (reach_floor objectives)
   - `on_monster_death` → `check_kill(monster_id)` for bosses (kill_boss objectives)
   - `_collect_item` → `check_collect(item_id)` (collect_item objectives)
   - `player_interact_event` → `check_interact(kind/rid)` (interact objectives)
   Completed quests grant rewards (essence, class unlocks, permanent upgrades, lore) and
   surface a "QUEST COMPLETE" notice.

2. **Profile persistence** (`game/systems/save.py`). Added `quests` field
   (`active`/`completed`/`progress`) to `default_profile`, `_norm_quests` guard, and both
   `save_profile` payload and `load_profile` (v2/v3 + native) paths.

3. **Quest HUD panel** (`game/ui/hud.py`). Active quests with `[x]`/`[ ]` objective
   progress render in the top-right corner (up to 3 quests, 4 objectives each).

4. **Quest chain progression** (`game/ui/hq_scene.py`). HQ now calls `accept_available()`
   so quests whose prereqs are satisfied get accepted automatically.

5. **Quest data reconciliation** (`game/data/quests.json`). Fixed id mismatches that would
   silently block completion: `boss_forge_colossus`→`forge_colossus`,
   `item_brokk_hammer`→`brokk_hammer`, `class_grave_warden`→`grave_warden`.

6. **secret_wall fix** (`game/data/rooms.json`). 4 `sunken_ossuary` secret rooms
   (`ossuary_room_secret_18/26/33/41`) were missing their `secret_wall` field. Added
   north/east/south/west.
