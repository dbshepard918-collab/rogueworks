## Code review verdict (chip)

### Light-map correctness: PASS
- Ambient fill `(232, 226, 240)` near-white — multiplication can only darken, so floor tiles read at ~65 luminance (dim but legible) without a lantern
- Cached radial gradients baked into **RGB** (not alpha) via `(1-t)^2` falloff — the old alpha-carrying gradient produced a flat disc at 1 distinct colour
- `_line_of_sight()` uses Bresenham in **LEVEL** tile space, called with `(player_tx, player_ty)` — correct coordinate space
- `_visibility_mask()` cache key `(id(level), player_tx, player_ty, len(level.tiles))` correctly invalidates on level change or player movement
- LRU (`clear()` when `len(_vis_cache) > 8`) is sensible for the ~900-ray cost

### Cost: PASS
- ~9 light sources per frame (1 player + ~8 props)
- `_radial_gradient()` caches per `(radius, colour)` — typically 5-8 distinct keys
- `_visibility_mask()` does ~900 Bresenham rays but is memoized per tile
- Shadow blit iterates at most 24×40 = 960 cells (pygame clips off-screen blits)
- Total estimated **~2-4ms per frame** on a modern CPU — headless `ms_per_tick=3.074` confirms the frame budget

### Contract verification: PASS
- `render_lighting(surface, world, ox, oy, dt)` signature matches `renderer.py:500`
- Called AFTER level/entities/effects (lines 488-497), so the light map composites on top of everything
- Lazy import (`from game.engine import lighting as _light` at renderer.py:499) avoids circular imports
- `try/except` in both `render_lighting` and `_compose_lightmap` ensures lighting never crashes the game

### Bugs found and fixed
1. **Dead flicker** — `flicker_phase` was set once at `LightSource.__init__` and never advanced by `dt`. `effective_radius` used `math.sin(self.flicker_phase)` with a constant phase, so the lantern radius was time-invariant. Fixed with `LightSource.tick(dt)` + call in `_compose_lightmap` loop.
2. **Shadow blit bounds** — `range(0, h + TILE, TILE)` iterated one extra row below the 720px surface. Pygame clips off-screen blits so it was harmless but wasted. Tightened to `range(0, h, TILE)`.
