# BUILD-2026-09-15-r53 — Critical bug fix + balance verification

## CRITICAL BUG FOUND (r52 regression)

In `game/systems/combat.py` line 255-258, r52 added VFX for player attacks but
placed the `if crit:` check **before** `crit = world.rng.chance(...)`:

```python
# BROKEN (r52):
world.particles.sprite_burst(...)  # VFX
if crit:                              # <-- crit not defined yet!
    world.particles.sprite_burst(...)
...
crit = world.rng.chance(...)          # defined too late

# FIXED (r53):
crit = world.rng.chance(...)          # define first
...
world.particles.sprite_burst(...)
if crit:
    world.particles.sprite_burst(...)
```

This caused an `UnboundLocalError` on every melee hit, crashing the combat
handler silently in the balance harness. All pre-r53 measurements are invalid.
