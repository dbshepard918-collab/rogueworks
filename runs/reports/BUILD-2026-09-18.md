### Root cause

The title screen background image was 1280×720. While width 1280 = 40×32 is grid-aligned, height 720 is not divisible by 32 (720/32 = 22.5). The `tools.art.verify` gate enforces that all sprite files are exact multiples of the 32px tile grid per CONTRACTS §5 and §2.

### Fix details

- Padded bottom 16px of `title_background.png` using the exact palette colour `ink` (#15131f), not a near-match. This matters because `tools.art.verify` uses tolerance 0 — any off-palette pixel counts as a FAIL.
- The padding colour was chosen by sampling the bottom edge of the existing image and finding the nearest palette entry (`ink` at distance 7.48, the closest of 26 palette colours).
- The atlas PNG and JSON were updated identically so the frame rect matches the actual image dimensions.
