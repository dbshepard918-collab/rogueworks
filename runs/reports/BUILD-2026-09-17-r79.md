### Root cause found and fixed

**Dialogue system was silently broken.** `game/systems/dialogue.py` resolved `DATA_DIR` to `game/game/data/` (a non-existent path) instead of `game/data/`. The 5 NPC greeting JSON files existed on disk but were never loaded. The old code used `Path(__file__).resolve().parents[1]` (→ `game/`) then `ROOT / "game/data"` (→ `game/game/data`). The fix uses `parents[2]` (→ project root) then `ROOT / "game" / "data"` (→ `game/data`).
