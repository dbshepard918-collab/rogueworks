# Build report — P4.6 Resolution Scaling (2026-09-15)

**Round:** P4.6 · **Owner:** forge · **Status:** PASS

## What changed

Implemented P4.6 Resolution scaling: windowed/fullscreen, integer-scale pixel-perfect
rendering at 1280x720 / 1920x1080 / 2560x1440, letterboxing, FPS cap, vsync toggle.

### Files modified

1. **`game/engine/scenes.py`** — `Game.__init__` now reads resolution from `profile["settings"]`
   and sets `self.render_size`, `self.display_size`, `self.display_scale`, `self.size`
   from the chosen mode instead of hardcoding (1280, 720). `RESOLUTION_MODES` is already
   imported from `game.ui.settings`.

2. **`game/main.py`** — Added `--resolution`, `--fullscreen`, `--vsync`, `--fps` CLI flags.
   `run_headless()` now resolves render size from profile settings and creates the
   canvas at the correct size. `run_windowed()` applies CLI overrides to profile settings.
   `RESOLUTION_MODES` imported from `game.engine.scenes`.

### Resolution modes (from `game/ui/settings.py`)

| Mode | Render size | Scale |
|---|---|---|
| `1280x720` | 1280×720 | 1× (native) |
| `1920x1080` | 1920×1080 | letterboxed (non-integer) |
| `2560x1440` | 2560×1440 | 2× pixel-perfect |

## Notes

- The render surface is always the base game logic resolution; the display surface
  scales it up (integer scale) or letterboxes it (non-integer scale).
- Headless mode uses the render surface directly as the canvas for frame capture.
- `settings.py` already had `resolution`, `fullscreen`, `vsync`, `fps_cap` in
  `DEFAULT_SETTINGS`; this ticket wires them into the actual engine.
