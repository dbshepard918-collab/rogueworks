## What changed

### game/engine/input.py
- `ReplayInput` expanded from a stub to a full record/replay engine:
  - `start_recording()` / `stop_recording()` — capture `InputState` (move + actions) per tick
  - `save(path)` / `load(path)` — serialize/deserialize to JSON replay file
  - States stored as `{"move": [mx, my], "actions": [...]}` dicts
  - Recording is opt-in via `--record` CLI flag

### game/main.py

- Added `--replay <path>` flag: feeds a recorded replay JSON deterministically back into `World.step()`
- Replay mode wires `game.replay` as the world's `input_source` before `start_run()`
