# BUILD report — 2026-09-16 (r77)

## Round goal

r76 wired the quest tracker into the run, but quests 2-4 referenced content that did not
exist (`brokk_hammer` item, `flood_gate_1/2/3` and `bone_altar` interactables). This round
ships that content so the quest chain is actually completable.

## What changed

1. **Brokk's Hammer** (`game/data/items.json`) — `brokk_hammer` (tier-4 weapon, damage 20 /
   crit 7 / armor 3, value 280) with `quest_only: true` so it never rolls in the normal loot
   pool. `pick_base_item` (loot.py) now skips `quest_only` items.

2. **Boss quest drop** (`game/data/monsters.json`, `game/systems/spawn.py`) — `forge_colossus`
   gained `quest_drop: "brokk_hammer"`; `drop_loot_for` drops a monster's `quest_drop` item
   guaranteed on death (with a floating name banner).

3. **Flood gates + bone altar** (`game/systems/procgen.py`, `game/systems/world.py`,
   `game/ui/hud.py`) — `_place_quest_props` places 3 `flood_gate_1/2/3` (`prop_pillar_drowned`)
   on every Drowned Vaults floor and 1 `bone_altar` (`prop_altar`) on every Sunken Ossuary
   floor, deterministically. `World._interact_quest_prop` triggers the matching `interact`
   objective when the player presses E adjacent; the HUD shows a "Press E to mark …" prompt.

4. **Schema** (`tools/validate_data.py`) — added `quest_drop` (monsters, ref items),
   `quest_only` (items, bool), `quest_props` (rooms, list of dicts).

5. **Quest data** (`game/data/quests.json`) — reconciled `boss_the_wound` → `the_wound`.
