## What changed

- `game/engine/profiler.py` (new): `Profiler` class with 5 metrics:
  - `entity_count` — live monsters + projectiles + pickups + player
  - `tick_ms` — milliseconds in last `world.step()`
  - `draw_calls` — entries in `world.render_list`
  - `particle_count` — active particles + damage numbers + floating text
  - `atlas_mem` — estimated atlas surface memory in bytes
  - Hard caps: `MAX_ENTITIES=200`, `PARTICLE_CAP=420`, `ATLAS_CAP=40MB`
  - Toggle via F1 key during run; renders in bottom-left corner with colour-coded values
  - `check_caps()` returns violation strings; `summary()` returns dict for JSON
- `game/engine/__init__.py`: Added `Profiler` import/export
- `game/engine/scenes.py`:
  - `RunScene.__init__`: creates `self.profiler = Profiler()`
  - `RunScene.handle_event`: F1 toggles `self.profiler.visible`
  - `RunScene.update`: calls `profiler.tick_start()`/`tick_end()` around `world.step()`, then `profiler.tick()` for counting
  - `RunScene.draw`: calls `profiler.draw(surface, self.world)`
  - `Game.run_headless()`: calls `profiler.frame_end()` after draw, exposes `world.profiler_summary = scene.profiler.summary()`
- `game/systems/world.py`: `summary()` now includes `metrics_profiler` key with profiler data
