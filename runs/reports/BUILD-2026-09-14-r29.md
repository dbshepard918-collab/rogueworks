against a 121 px body). Instead of re-rendering art, `tools/art/despeckle.py` clears connected

## 3. Critique-loop regression: numbered labels made the VLM worse

Attempted improvement, measured, reverted. Drawing an index number above each cell made the model
regurgitate `1, 2, 3, ... 188` instead of judging art — the labels became the task.

Reverted to unnumbered cells with a position-based rubric ("row R, column C"), and added
`cell_for_position(mapping, cols, row, column)` so a positional finding resolves back to an exact
frame name. The mapping is printed in the JSON report. Resolver verified:

```

  row  2 col  3 -> monster_coal_hound_elite (monsters)
  row  5 col 16 -> prop_chest_open (props)
  row 13 col  5 -> boss_skull_overlord (bosses)
```

## 5. Gate gap closed — and it found three more latent crashes

`module-attributes` only inspected `module.attr` accesses, so a **bare name with no definition**
was invisible to it. That is why `set_audio_singleton` reached a running game.

`tools/qa/attr_audit.py` now also collects every name a module binds (module scope, args, locals,
loop/comprehension targets, nested defs, imports) and flags reads that are bound nowhere. Files
with a star-import are skipped; precision is deliberately favoured over recall so the gate stays
trustworthy.

Proven against the real defect, not a synthetic one — the exact file that shipped the bug:

```
undefined names in the version that shipped the bug: [('_audio_singleton', 289),
                                                      ('_audio_singleton', 296),
                                                      ('set_audio_singleton', 97)]
CATCHES set_audio_singleton: True
```

Run against the tree, it immediately found **three more player-reachable crashes**, all in the
P3.2 secret-room / cracked-wall code paths that no gate exercises:

| File | Defect | Consequence |
|---|---|---|
| `game/ui/minimap.py:86-87` | `TILE` used, never imported | minimap raises `NameError` on the hidden-door highlight |
| `game/systems/world.py:1388,1403,1454,1467` | bare `FLOOR`, module uses `procgen.FLOOR` everywhere else | digging a cracked wall raises `NameError` |
| `game/systems/world.py:1364,1406,1470` | `from procgen import _room_from_data` — absolute import of a package-relative module | `ModuleNotFoundError` on the same path |
| `game/engine/scenes.py:355` | bare `tree_state(profile)`, line 341 correctly uses `meta_sys.tree_state` | **buying an upgrade in the meta shop crashes** |

All four fixed. `attr_audit` → `OK: every referenced attribute resolves`; selftest 19/19.
