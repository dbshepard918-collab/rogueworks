## What changed

1. **Daily seeded run** (`--daily` flag): seed = `int(time.strftime("%Y%m%d"))` = today's date
   as YYYYMMDD. MenuScene adds "Daily descent (seed N)" entry. All players share the same
   seed on a given day.

2. **Cursed run** (`--curses id1,id2,...` flag): comma-separated curse ids applied at run
   start. Each curse adds +15% essence multiplier (`essence_mult = 1.0 + 0.15 * len(curses)`).
   `CurseSelectScene` lets the player toggle curses on/off before starting a run.
   MenuScene adds "Cursed descent" entry.

3. **Endless mode** (`--endless` flag): after floor 15 (MAX_FLOOR), instead of victory the
   game continues to floor 16+. Each floor past MAX_FLOOR gets
   `endless_scale = 1.0 + 0.2 * (floor - MAX_FLOOR)` applied as +HP% and +damage% to all
   monsters. `_check_exit` only triggers `on_victory` when `not self.endless`.

4. **Contract fix (SLAP #19):** `docs/CONTRACTS.md` §4 items.json field list was missing the
   `unique` field (optional, marks build-defining legendaries). Added.
