## Implemented

`game/systems/save.py`:
- `SAVE_VERSION` bumped from 2 → 3.
- v2→v3 migration in `load_profile()` copies all existing fields forward (additive) and fills `save_slots` and `autosave` with defaults when missing.
- `save_slots` dict added to `default_profile()`: `{"default": "save.json", "autosave": "save_autosave.json"}`.
- `autosave` metadata dict added: `{"last_floor": 0, "last_biome": "", "last_seed": 0, "timestamp": 0}`.
- `save_profile()` writes `.bak` backup after atomic write (`shutil.copy2(target, target + ".bak")`).
- `load_profile()` recovers from `.bak` on corrupted JSON (ValueError), falling back to fresh profile only if both are unusable.
- New slot functions: `_slot_path()`, `list_saves()`, `load_slot(slot_name)`, `save_slot(slot_name, profile)`.
- `save_profile()` accepts `slot_name` param to write to named slots.

`game/systems/world.py`:
- `World.__init__` initializes `self.previous_floor = 0`.
- `new_floor()` autosaves to `save_autosave.json` when `floor != previous_floor`, updating autosave metadata. Guarded by try/except so autosave failure never breaks gameplay.
