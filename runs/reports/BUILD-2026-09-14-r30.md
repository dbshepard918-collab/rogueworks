## What changed

### game/engine/audio.py — manifest-driven audio (chip's lane, forge-delegated)
- `set_biome()` now loads the actual .wav file from `game/data/audio.json` via `load_audio_cue()` instead of synthesizing a 60Hz procedural drone. Catacombs loads `amb_catacombs.wav`, ember loads `amb_ember.wav`, drowned loads `amb_drowned.wav`.
- `play_title_theme()` loads `title_theme.wav` from the manifest instead of synthesizing a 440Hz tone.
- **New `play_death()`** loads and plays `death_sting.wav`.
- **New `play_victory()`** loads and plays `victory_sting.wav`.
- `_BIOME_AMBIENCE` `drowned_vaults` entry fixed: was `{"music": None, "loop_gain": 0.0}`, now `{"music": "music_drowned_vaults", "loop_gain": 0.10}` matching `biomes.json`.
- Module-level audio singleton added (`set_audio_singleton`/`get_audio_singleton`) enabling module-level `play_death()`/`play_victory()` convenience functions.

### game/engine/scenes.py — death/victory stings
- Import added: `play_death, play_victory` from `..engine.audio`.
- `EndScene.draw()` now calls `play_victory()` if victory, else `play_death()`.
