# BUILD-2026-09-15-r54 — Animated environment: hazard tiles, prop ground glow, torch flicker

## What changed

### Problem
VLM audit of real gameplay frames (seed 3, catacombs) reported: "repeating dark stone tiles, no animated or hazard tiles; all environmental elements are static." The tile atlas has 128 biome frames but the renderer never animated any of them.

### Solution

**1. Animated tile frame cycling**
- Added `self._tile_anim_tick` to `Renderer.__init__`, advanced by `dt` in `draw()`
- Added `Renderer._resolve_tile_frame(name, anim_tick, tileset)` — deterministic time-based lookup into `ANIMATED_TILES` dict
- Wired into 3 tile-drawing sites:
  - `floor_burning` → cycles `floor_burning` / `floor_burning_alt` at 0.25s
  - `floor_water` → cycles `floor_water` / `floor_water_alt` at 0.35s  
  - `wall_torch` → cycles `wall_torch` / `wall_torch_bright` at 0.18s
- Periods chosen to be visually distinct; no RNG used (deterministic)

**2. Prop ground glow**
- Added `PROP_GLOW` dict mapping prop sprites → (color, radius, alpha)
- After drawing each prop, if it's light-emitting, stamp an additive glow disc on the floor
- Colors match `lighting.py` spec: brazier (255,120,40), candles (255,200,80), lava_vent (255,80,20), etc.

**3. New tile sprites (20 total)**
- Generated via numpy pixel manipulation + palette snap:
  - `tile_{biome}_floor_burning` (4 new — base frames from floor_rubble + fire tint)
  - `tile_{biome}_floor_burning_alt` (4 — brighter variant)
  - `tile_{biome}_floor_water` (4 new — base frames from pool + water tint)
  - `tile_{biome}_floor_water_alt` (4 — brighter variant)
  - `tile_{biome}_wall_torch_bright` (4 — brighter torch variant)
- All snapped to 26-color vaelmoor palette
- Packed into `assets/atlas/tiles.png` (148 frames, 512×320)
