# Build Report — P4.3 Audio
**Date:** 2026-09-13
**Item:** P4.3 Audio

## Changes

### game/engine/audio.py — complete rewrite
- `Audio.play(name, pos=None)`: inverse-square distance attenuation (_MIN_RANGE=32px → _MAX_RANGE=512px). `pos` is a `(tx, ty)` tile position; volume scales by 1/(1 + (dist - min)^2 * rolloff).
- `Audio.set_biome(biome_id)`: switches the looping ambience track per biome. Catacombs → `music_catacombs_drip`, Ember → `music_ember_warrens`, Drowned → `music_drowned_vaults`.
- `Audio.play_title_theme()`: plays the title theme once. Called from `MenuScene.draw()`.
- `Audio.play_door(pos=None)`: door-creak SFX with distance attenuation. Wired into `_unlock_doors()` in `world.py`.
- `Audio.play_stairs(pos=None)`: stairs SFX with distance attenuation. Replaces `play(self, "stairs")` in both `_check_exit()` methods in `world.py`.
- `save_wave_state(path)` / `load_wave_state(path)`: persist/restor audio state.
- Graceful degradation preserved: `Audio(enabled=False)` → `ok=False`, all play calls return silently.

### game/data/biomes.json — audio fields added
- Each biome now carries `ambient_sound` ({frequency, pattern, volume}), `attenuation` ({min_distance, max_distance, rolloff}), `sfx_events` ({footstep, door, hit, death} → sound names).
- `drowned_vaults.music` changed from `null` to `"music_drowned_vaults"`.

### game/systems/data.py — fallback biomes updated
- `_FALLBACK_BIOMES` entries updated with matching `ambient_sound`, `attenuation`, `sfx_events` fields.

### tools/validate_data.py — schema updated
- `biomes.json` schema extended with `ambient_sound`, `attenuation`, `sfx_events` as optional dict fields. No warnings emitted.

### game/engine/__init__.py — exports updated
- Exports `Audio`, `play`, `save_wave_state`, `load_wave_state`.

### game/engine/scenes.py — title theme wired
- Imports `Audio, play`. `MenuScene.draw()` calls `Audio.play_title_theme()` (guarded, only in windowed mode).

### game/systems/world.py — audio events wired
- `self.audio.set_biome(self.biome_id)` called in `new_floor()`.
- `self.audio.play_door(pos=...)` called in `_unlock_doors()`.
- `self.audio.play_stairs(pos=...)` replaces `play(self, "stairs")` in `_check_exit()`.

### docs/CONTRACTS.md — updated §4
- Added `ambient_sound`, `attenuation`, `sfx_events`, `secret_rooms` to `biomes.json` row.
