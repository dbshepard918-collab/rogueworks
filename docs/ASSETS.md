# Assets — Depths of Vaelmoor

All sprite art is generated by the `pixel` bot (image model) and finished by the deterministic
pipeline in `tools/art/`. **Raw AI output is never shipped.**

## Pipeline

```bash
python -m tools.art.build_from_manifest        # 1-6 below, one command
python -m tools.art.verify                     # gate: palette-locked, grid-aligned, alpha intact
```

1. **Prompt for sheets, not sprites** — one `image_generate` call = a 4x4 grid (or 8x4 tiles/3x1
   bosses) of 32px-grid subjects on a flat `#ff00ff` background. 18 raw sheets, 1 call each.
2. **Stage** (`assets/raw/` → `assets/raw/staged/`): square-crop each painted cell, palette-snap it at
   *source* resolution (anti-aliased AI art downscaled directly turns to noise — snapping first makes
   flat colour regions), then BOX-downscale to exactly 32x32. Key colour preserved.
3. **Chroma-key + palette lock** (`tools.art.pixelize --split manifest`) → `assets/sprites/<set>/`.
   Magenta family → alpha; every remaining pixel snaps to the locked palette
   (`assets/palette.json`, 26 colours, tolerance 0).
4. **Pack** (`tools.art.pack_atlas`) → `assets/atlas/<set>.png` + `<set>.json` with real frame names.
5. **Aliases** → `assets/aliases.json` (alias → real frame), resolved by the game loader.
6. **Verify** → the gate above. No two frames may share a rect; every frame is 32x32.

Source of truth for frame names: `assets/art_manifest.json` (`sheets[].frames`, row-major, `null` =
unpainted cell).

## Shipped sets

| Atlas | Frames | Contents |
|---|---|---|
| `monsters` | 48 | 37 monsters + elite variants across the three biomes |
| `items` | 64 | 15 weapons, 15 armour, 17 trinkets, 17 consumables |
| `tiles` | 96 | 32 tiles x 3 biomes (floor/wall/door/stairs/pool/grate/brazier/trap-safe décor) |
| `props` | 32 | chests, keys, coin piles, potions, shrine, traps, crates, barrels, decor |
| `player` | 16 | 4 facings x (idle, walk x2, attack) + hurt and dash |
| `vfx` | 16 | slash, impact, blood, ember, magic bolt, poison cloud, dust, shockwave, level-up |
| `ui` | 16 | hp/xp bars, 6 status icons, ability icons, minimap frame, panel, slot |
| `bosses` | 3 | skull overlord, forge colossus, drowned leviathan |

Plus `assets/aliases.json` (39 alias frame names, e.g. every status icon id maps to a painted icon)
and `assets/placeholder/` fallbacks so the game runs with no atlas at all.

## Visual QA

`docs/preview_art.png` is a 4x nearest-neighbour contact sheet of every shipped frame — the artefact
the art director reviews (and the vision model audits). Regenerate with the montage step in
`tools/art/build_from_manifest.py`'s sibling temp script, or by re-running the audit below.
