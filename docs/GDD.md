# Roguelite — Game Design Document v1

Working title: **Depths of Vaelmoor**. Genre: top-down action roguelite with meta-progression.
Platform: Windows desktop, Python 3.11 + pygame-ce, 1280x720, 60 Hz fixed-step simulation.
Reference feel: *Hades* pacing with *Binding of Isaac* room structure and *Diablo* loot vocabulary.

## 1. Fantasy

You are a Lantern-Keeper descending into Vaelmoor, a flooded catacomb city that rearranges itself
every time you die. You carry one lantern; when it gutters, the dungeon keeps what you found and you
keep only *essence* — the currency that permanently sharpens you for the next descent.

## 2. Core loop

`Menu -> Run (5 floors of a biome) -> Boss -> Next biome -> ... -> Victory or Death -> Meta upgrades -> Menu`

- A **run** = 3 biomes (Catacombs, Ember Warrens, Drowned Vaults) x 5 floors each, capped by a boss
  every 5th floor (3 bosses total), then a final victory screen.
- A **floor** = a procedurally generated room-and-corridor level (48x32 to 80x56 tiles), entered at a
  spawn room; the exit is a staircase that unlocks once the floor's guardian count is cleared or a key
  is found (biome-dependent).
- **Death is progress**: essence earned converts to permanent meta upgrades (max HP, damage, move
  speed, luck/rarity, essence gain). Meta is saved immediately; run state is not.

## 3. Player

- Movement: WASD/arrows, 8-directional, `speed` in tiles/sec (base 4.2).
- Attack: melee swing in the facing arc **automatically when a monster is inside the weapon's reach**
  (keeps the sim deterministic and readable in screenshots), plus a ranged/aimed attack bound to
  SPACE that fires a projectile in the facing direction with a cooldown.
- Dash: SHIFT, 0.15 s burst, 0.8 s cooldown, i-frames for the duration. This is the dodge window and
  the skill ceiling of the game.
- Stats: `max_hp`, `damage`, `armor`, `speed`, `crit`, `luck`. Items and meta upgrades modify them;
  all modifiers resolve through one `Stats` object — never ad-hoc arithmetic in the combat code.
- Levels: XP from kills, level-up grants +1 to a chosen stat (auto-pick with a seeded RNG when
  headless), full heal every 3rd level.

## 4. Monsters

Data-driven from `game/data/monsters.json`. Four behaviors:
`chaser` (pathfind toward player), `ranged` (keep distance, fire projectiles on a cooldown),
`ambusher` (idle until inside trigger radius, then fast burst), `brute` (slow, high hp, telegraphed
heavy hit). Spawn tables are per-biome with a floor-scaled budget; elites (tier+1, extra affix, glow)
appear with increasing probability, and a **guardian** (unique monster, 3x hp, drops a key) holds the
stairs on most floors.

## 5. Loot and items

- Pickups: gold, essence, health orbs, keys, chests (open on contact, spawn 1-3 items).
- Items have a slot (weapon / armor / trinket / consumable), tier 1-5, and 0-2 rolled **affixes**.
- Rarity from tier + luck: common / uncommon / rare / epic / legendary, each with its own colour and
  drop weight. Legendaries get a flavour line on pickup.
- Inventory: 3 equipment slots + 4 consumable slots; equip/swap in an overlay (TAB), auto-pickup only
  for upgrades when the slot is empty or the tier is higher.
- Items are the run's texture: a run's build should read as identifiable within 30 seconds of play
  (e.g. "poison crit daggers" vs "armor-stacking warhammer").

## 6. Statuses

`statuses.json` drives poison/burn/bleed/stun/slow/fortify/rage. DOTs tick on their own cadence;
debuffs affect the target's stats; icons render under the HUD bar with remaining duration.

## 7. Presentation

- **Art**: 32x32 pixel art, one locked palette, generated by `pixel` (image model -> palette lock ->
  atlas). Biome tile sets, monsters, player (idle/walk/hurt/death), projectiles, pickups, props, UI
  frames and icons.
- **Camera**: follows the player with dead-zone + smoothing, clamped to level bounds, 1 px snap (no
  subpixel blur).
- **Juice (required, not optional)**: hit flash (white 80 ms), screen shake on heavy hits and boss
  slam, damage numbers, particle burst on death/hit, footsteps, dust on dash, light vignette around
  the player that dims with distance, floor-transition fade, health-bar wobble.
- **HUD**: HP bar, XP bar + level, essence counter, floor/biome label, minimap (visited rooms, player,
  stairs, shop), status icons, ability cooldowns.
- **Menus**: main (New run / Continue / Meta upgrades / Quit), death screen with run stats, victory
  screen, meta-upgrade shop with prices.

## 8. Audio

Optional and never a blocker: generate simple procedural sfx (hit, death, pickup, level-up) with
stdlib `wave`/`array` if time allows; the game must run silently and happily with no audio device.

## 9. Non-goals (v1)

Multiplayer, controller support, mod support, online leaderboards, 3D, mobile.

## 10. Definition of done for v1

1. `python -m game.main` opens a window and is playable with WASD + SPACE + SHIFT + TAB.
2. `python -m game.main --headless --turns 300 --seed N` exits 0 for seeds 0..7, invariants clean.
3. 3 biomes x 5 floors generate, connect, and are completable (verified by a scripted auto-run).
4. At least 12 monsters, 60 items, 25 affixes, 3 bosses, 3 tilesets shipped as packed atlases.
5. Meta upgrades persist across restarts; save/load round-trips.
6. `runs/reports/` holds a QA report with real screenshots and a `PASS-WITH-ISSUES`+ verdict.
